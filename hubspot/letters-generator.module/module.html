Letters & Statements (for Mailing)

This tool builds a past‑due letter + statement for every customer with an open, past‑due balance — for mailing (not tied to tomorrow's orders).

It produces two PDFs, which both download automatically:

  • Billing — every qualifying customer.
  • Shipping — only customers whose shipping address differs from their billing address (same‑address customers are in the Billing PDF only).

Each account is a letter (sheet 1) + statement (sheet 2), grouped by route.

Set the filters, click Generate. Large runs can take a few minutes — keep this page open.
